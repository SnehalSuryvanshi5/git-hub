# Zeal College Website

A simple responsive college website built using HTML, CSS, and JavaScript.

## Features

- Responsive design
- Home, About, Courses, and Contact sections
- Interactive button using JavaScript
- Easy to customize

## Project Structure

```
zeal-college-website/
│
├── index.html
├── style.css
├── script.js
├── package.json
└── README.md
```

## Installation

1. Clone or download the project.
2. Install Node.js.
3. Run:

```bash
npm install
npm start
```

4. Open the displayed localhost URL in your browser.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Node.js (for local server)
