# Heritage International School Website

A responsive school website built using HTML, CSS, and JavaScript.

## Features

- Responsive design
- Hero section
- About section
- Academics section
- Admissions section
- Contact information
- Smooth scrolling navigation

## Installation

```bash
npm install
```

## Run Locally

```bash
npm start
```

The website will be available at:

http://localhost:3000

## Technologies Used

- HTML5
- CSS3
- JavaScript
